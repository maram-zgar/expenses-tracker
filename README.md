# Expenses Tracker

A personal, single-user mobile app for tracking monthly spending — set a starting bank balance and a monthly budget, log expenses into categories like food, transport, home needs, and rent, and see exactly where the money goes through built-in statistics. Built as a full-stack project (Expo/React Native frontend, Node.js/Express backend, PostgreSQL database) with no authentication layer, since it's designed for personal use only.

## Tech Stack
- **Frontend:** React Native (Expo), TypeScript
- **Backend:** Node.js v20, Express, TypeScript
- **Database:** PostgreSQL 16 + Prisma ORM
- **Other:** Axios for API calls, chart library for statistics visualization

## Features
- Set and edit bank balance + monthly budget
- Log expenses under customizable categories
- Dashboard with remaining budget at a glance
- Spending statistics by category and over time
- No login — fully local/personal use
